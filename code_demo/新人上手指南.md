# YOLO11n RK3588 三核 NPU 推理 — 新人上手指南

本项目在 **正点原子 ATK-DLRK3588** 开发板上运行 INT8 量化的 YOLOv11n 目标检测，
接入 ATK-MCIMX415 摄像头，实测相机模式约 **30 FPS**。

---

## 目录结构

```
code_demo/
├── 新人上手指南.md          ← 你正在看的文件
├── ubuntu_side/             ← 在 Ubuntu 电脑上操作
│   ├── setup_ubuntu.sh      ← 一键安装 Ubuntu 编译依赖
│   ├── build.sh             ← 一键交叉编译脚本
│   └── cpp_src/             ← 完整 C++ 源码（自包含，无外部依赖）
│       ├── main.cc          ← 主程序（三核 NPU 并发推理管线）
│       ├── v4l2_capture.h/cc← V4L2 摄像头采集
│       ├── yolo11_cpp/      ← YOLO11 后处理（DFL decode + NMS）
│       ├── utils/           ← 图像工具（RGA 预处理、画框、文件读写）
│       └── 3rdparty/        ← 预编译库（librknnrt、librga、libturbojpeg）
└── rk3588_side/             ← 传到板子上运行
    ├── run.sh               ← 一键运行脚本
    ├── yolo11n_rk3588.rknn  ← INT8 量化模型
    └── lib/
        └── librknnrt.so     ← RKNN Runtime v2.3.2
```

> `rk3588_side/camera_yolo11_3core` 是编译产物，需先运行 `build.sh` 生成。

## 第一步：Ubuntu 电脑准备

### 1.1 安装编译依赖

需要安装的系统工具（**仅这 4 个，其余 C++ 库已全部自包含在 `cpp_src/3rdparty/` 中**）：

| 包名 | 用途 |
|------|------|
| `gcc-aarch64-linux-gnu` | ARM64 交叉编译器（C） |
| `g++-aarch64-linux-gnu` | ARM64 交叉编译器（C++） |
| `cmake` | 构建系统 |
| `make` | 构建工具 |

**方式一：一键安装（推荐）**

```bash
cd code_demo/ubuntu_side
chmod +x setup_ubuntu.sh
./setup_ubuntu.sh
```

**方式二：手动安装**

```bash
sudo apt update
sudo apt install -y gcc-aarch64-linux-gnu g++-aarch64-linux-gnu cmake make
```

验证安装：
```bash
aarch64-linux-gnu-g++ --version
# 应输出：aarch64-linux-gnu-g++ 11.x.x ...
```

### 1.2 编译

```bash
cd code_demo/ubuntu_side   # 如果不在此目录
chmod +x build.sh
./build.sh
```

编译成功后，`rk3588_side/` 目录下会自动生成：
```
rk3588_side/
├── camera_yolo11_3core   ← 可执行文件（新出现）
├── lib/
│   ├── librknnrt.so      ← 已有
│   └── librga.so         ← 已有
├── run.sh
└── yolo11n_rk3588.rknn
```

## 第二步：连接 RK3588 板子

### 2.1 获取板子 IP

**方式一：串口查询**

用 USB 线连接板子的调试串口，Ubuntu 上打开终端：
```bash
# 安装串口工具（如未安装）
sudo apt install -y screen

# 打开串口（设备节点通常是 /dev/ttyACM0）
sudo screen /dev/ttyACM0 1500000
# 登录：用户名 root，密码 1
```

登录后执行：
```bash
ifconfig | grep "inet "
# 或
ip addr show
```

退出 screen：按 `Ctrl+A`，再按 `K`，输入 `y` 确认。

**方式二：路由器管理页**

在路由器后台的已连接设备列表中查找 RK3588 对应的 IP。

> **注意**：串口调试时避免乱按按键，某些字符序列会触发 Rockchip FIQ 调试器（进入后输入 `console` 回车可退回 Linux shell）。

### 2.2 连接摄像头

将 ATK-MCIMX415 摄像头接入板子 **CSI3 接口**，开机后验证：
```bash
ls /dev/video*
# 应看到 /dev/video22（ISP 输出节点）
```

## 运行模式说明

### 模式一：相机模式（默认）

```bash
./run.sh
# 等价于：
./camera_yolo11_3core --model_path yolo11n_rk3588.rknn --num_frames 200 --save_every 30
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--num_frames` | 200 | 推理总帧数（-1 为无限运行） |
| `--save_every` | 30 | 每 N 帧保存一张带框结果图 |

**实测帧率：~30 FPS**（受 ISP 30 FPS 限制）

### 模式二：NPU Benchmark 模式

测量纯 NPU 吞吐上限。程序仍需连接摄像头（启动时采集一帧作为初始帧），之后在内存中循环喂帧，消除 ISP 帧率限制。

```bash
./run.sh --benchmark --num_frames 300
```

**实测帧率：~52 FPS**

### 模式三：录制带框视频

每帧都保存结果图，然后用 ffmpeg 合成视频：

```bash
# 0. 设置动态库路径（直接调用二进制时需要，run.sh 已自动设置）
export LD_LIBRARY_PATH=/userdata/rk3588_side/lib:$LD_LIBRARY_PATH

# 1. 保存所有帧
./camera_yolo11_3core --model_path yolo11n_rk3588.rknn --num_frames 90 --save_every 1 2>/dev/null

# 2. 合成视频（1920×1080）
ls /userdata/results3/frame_*.jpg | sort | awk '{print "file " $0}' > /tmp/frames.txt
ffmpeg -y -f concat -safe 0 -i /tmp/frames.txt -r 30 -vf scale=1920:1080 -c:v libx264 -crf 23 -pix_fmt yuv420p /userdata/output.mp4

# 3. 传回 Ubuntu 电脑（在 Ubuntu 上执行）
scp root@<板子IP>:/userdata/output.mp4 ./
```

**注意**：录制模式帧率会下降到约 20 FPS（每帧写 4K JPEG 有 IO 开销）。

## 常见问题

### Q1：`/dev/video22: No such file`

摄像头未正确连接，或驱动未加载。检查：
```bash
dmesg | grep imx415
ls /dev/video*
```

### Q2：`ERROR: V4L2Capture open failed`

有残留进程占用摄像头，执行：
```bash
pkill -9 camera_yolo11_3core
fuser /dev/video22 | xargs -r kill -9
sleep 1
```

### Q3：终端被大量 `RGA_COLORFILL fail` 刷屏

这是已知现象（RGA letterbox 背景填充在此板上失败，有 CPU 回退，不影响推理正确性），屏蔽方式：
```bash
echo 3 > /proc/sys/kernel/printk   # 屏蔽内核日志
# run.sh 已自动执行此命令
```
或在命令末尾加 `2>/dev/null`。

### Q5：启动时打印 `Open ./model/coco_80_labels_list.txt fail!`

这是正常现象，程序尝试加载 COCO 标签文件失败后会自动使用数字类别编号继续运行，**不影响推理结果**，忽略即可。

### Q4：`cannot open shared object file: librknnrt.so`

运行时找不到动态库，执行：
```bash
export LD_LIBRARY_PATH=/userdata/rk3588_side/lib:$LD_LIBRARY_PATH
# run.sh 已自动设置
```
